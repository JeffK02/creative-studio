HOW TO SET UP A PRODUCT
=======================

Copy this whole folder, rename it after the product (lowercase, hyphens,
no spaces). Example: acme-hair-serum

Four things to do.


1. links.txt                                              REQUIRED

   Paste in the URLs, one per line. Delete the example lines.

     - the landing page
     - the advertorial
     - the checkout page  (this is where pricing and bundles live)

   That's all the product information the system needs. It reads the name,
   the price of every variant, the offer, and the problem it solves off
   these pages itself.


2. reference\                                             REQUIRED

   Drop in 3-5 clean photos of the product itself. Front, angle, in
   someone's hand, on white.

   These keep the packaging consistent across every ad the system makes,
   so use the sharpest ones you have.


3. winners\  and  losers\                                 REQUIRED

   Drop the winning creative images into winners\, and 2-3 that did NOT
   perform into losers\.

   IMPORTANT: name each image file after its Ad name in Ads Manager.
   If the ad is called "w_001" the file must be w_001.jpg. That is how
   the metrics get matched to the images.

   The losers matter more than they look. Without them the system can't
   recognise what failure looks like, and it will confidently propose
   angles that already flopped.


4. metrics.csv                                            REQUIRED

   In Ads Manager, filter to these ads, then Reports > Export > CSV.
   Save it into this folder as metrics.csv.

   Export it however you normally do - the columns are matched by name,
   so the default export works. It needs to include, at minimum:

     Ad name, Amount spent, CTR, CPM, ROAS, conversion rate

   Don't reformat it. Don't retype the numbers. Export and drop it in.


OPTIONAL
--------

   copy.md     the ad copy that ran with the winners, pasted
   notes.md    anything else worth knowing, free text
               "sells best to women 45+", "supplier changed the formula
               in July", whatever


_derived\ is generated by the system. Don't edit anything in there.
